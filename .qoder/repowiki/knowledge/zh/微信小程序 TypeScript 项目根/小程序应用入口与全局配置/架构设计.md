本模块由五个顶层文件组成，职责清晰分离：
- `app.ts` 为小程序入口，通过 `App()` 钩子初始化 `globalData`（userInfo、storeId），在 `onLaunch` 中调用 `utils/auth` 判断登录态并跳转登录页。
- `app.json` 声明所有 pages 路由、tabBar（自定义组件）、window 全局窗口样式，并启用 Skyline 渲染器与 glass-easel 组件框架。
- `config.ts` 集中导出 `BASE_URL` 与 `DEFAULT_STORE_ID`，作为全项目 API 地址与默认店铺 ID 的唯一修改点。
- `app.scss` 引入 `styles/variables.scss` 中的设计令牌（颜色、间距、圆角等），提供 `.container`、`.card`、`.btn-*`、`.tag`、`.divider` 等通用 UI 类。
- `sitemap.json` 允许所有页面被索引。
依赖方向单向向外：入口仅依赖 `utils/auth`，其余文件无运行时依赖，属于纯配置与样式层。
