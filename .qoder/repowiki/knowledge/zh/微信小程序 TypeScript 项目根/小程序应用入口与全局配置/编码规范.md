- 全局常量统一集中在 `config.ts` 中以 ES module 形式导出，避免硬编码分散在各处。
- 应用启动时优先检查本地登录态（`isLoggedIn` + `getUserInfo`），未登录则直接 `wx.redirectTo` 到 `/pages/login/login`。
- SCSS 样式通过 `@import './styles/variables.scss'` 引入设计令牌，所有页面级样式以 `page {}` 根选择器覆盖默认主题。
- UI 组件类名采用 BEM 风格前缀（如 `.btn-primary`、`.tag-primary`、`.safe-bottom`），保持命名一致性。
