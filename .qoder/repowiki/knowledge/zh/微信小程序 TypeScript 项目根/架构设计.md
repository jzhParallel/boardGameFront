根目录作为小程序工程的脚手架与构建契约层：`project.config.json` 指定 `miniprogramRoot` 为 `miniprogram/`，并通过 `useCompilerPlugins` 启用 TypeScript 与 Sass 编译器插件；`tsconfig.json` 将 `./typings` 注册为 `typeRoots`，所有子模块共享同一套严格 TS 编译选项（strictNullChecks、noUnusedLocals 等）；`typings/index.d.ts` 通过 `/// <reference>` 聚合 `types/wx/*` 的微信 API 类型以及 `AppUserInfo`、`IAppOption` 等跨页面通用的全局接口，使 app_entry 与各业务页面在类型层面保持契约一致。
