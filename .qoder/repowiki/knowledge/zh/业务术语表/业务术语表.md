### 登录页
- 定义：小程序中专门用于用户认证的页面（/pages/login/login），在未登录状态下访问受保护页面时自动跳转至此。页面加载后会自动触发 wx.login() 获取 code 并调用后端换 token，成功后返回原页面或首页。
- 别名：login 页面、认证页

### 登录态
- 定义：用户成功登录后在本地存储的认证状态，包含 token 和用户信息。应用启动时检查登录态，若存在则恢复用户信息，否则跳转登录页。token 过期时后端返回 401，前端自动清除并引导重新登录。
- 别名：token、认证状态

### wx-login
- 定义：微信登录接口，小程序端通过 wx.login() 获取 code 后调用后端 /api/auth/wx-login 换取 token 和用户信息。是小程序端主要的登录方式。
- 别名：微信登录接口、code 换 token

### 账号密码登录
- 定义：店员或管理员使用的传统登录方式，通过调用 /api/auth/login 接口传入 account 和 password 进行认证，成功后同样返回 token 和用户信息。
- 别名：account login、后台登录

### 401 处理
- 定义：当后端返回 401 未授权错误时的统一处理逻辑：清除本地 token、显示提示、防重复跳转至登录页。防止多个并发请求同时触发多次跳转。
- 别名：未授权处理、token 过期处理

### BASE_URL
- 定义：后端 API 的基础地址配置，当前指向 http://localhost:8080。所有请求都会在此基础 URL 上拼接具体路径。
- 别名：API 地址、后端地址
