## 核心组件
导航栏组件承担以下职责：
- 统一渲染顶部导航区域（标题、左侧返回/图标、右侧操作区）
- 管理页面标题与动态更新
- 处理返回行为（兼容小程序默认返回与自定义返回）
- 暴露事件回调（点击左侧按钮、右侧操作、搜索触发等）
- 提供样式与主题扩展点（背景色、高度、字体颜色等）

## 架构总览
导航栏组件通过属性接收父级页面的配置，并在内部维护状态（如是否显示搜索框、当前标题、按钮可见性等）。其数据流如下：
- 父页面在 wxml 中引入组件并传入 props（标题、左右按钮、背景样式等）
- 组件根据 props 渲染 UI，并监听用户交互事件
- 组件通过事件向上抛出（如 onLeftTap、onRightTap、onSearch），由父页面处理业务逻辑
- 对于返回行为，组件优先遵循小程序默认返回；若父页面禁用默认返回，则交由自定义返回逻辑处理

```mermaid
sequenceDiagram
participant Page as "父页面"
participant Nav as "导航栏组件"
participant System as "小程序系统"
Page->>Nav : 传入配置(标题/左右按钮/样式)
Nav-->>Page : 渲染完成
User->>Nav : 点击左侧/右侧按钮或搜索
Nav-->>Page : 触发对应事件回调
User->>System : 触发系统返回
alt 启用默认返回
System-->>Page : 执行默认返回
else 禁用默认返回
Nav-->>Page : 触发自定义返回回调
Page-->>System : 调用返回API
end
```

### 页面导航逻辑与返回处理
- 默认返回：当未禁用系统返回时，点击返回按钮直接执行小程序默认返回
- 自定义返回：当父页面禁用默认返回时，组件触发自定义返回回调，由父页面决定返回策略（如关闭弹窗、清空表单后再返回）
- 页面栈管理：避免重复入栈与异常返回路径，确保返回顺序符合预期

```mermaid
flowchart TD
Start(["进入页面"]) --> CheckDefault["检查是否启用默认返回"]
CheckDefault --> |是| UseSystem["使用系统返回"]
CheckDefault --> |否| EnableCustom["启用自定义返回"]
UseSystem --> End(["结束"])
EnableCustom --> OnBack["监听返回事件"]
OnBack --> HandleLogic["执行自定义返回逻辑"]
HandleLogic --> CallAPI["调用返回API"]
CallAPI --> End
```

## 故障排查指南
- 标题不更新
  - 检查属性是否正确传入
  - 确认动态更新逻辑是否被触发
- 返回行为异常
  - 确认是否禁用了默认返回
  - 检查自定义返回回调是否调用正确的 API
- 搜索无响应
  - 检查搜索开关是否开启
  - 确认输入事件与搜索按钮点击事件绑定正确
- 样式错乱
  - 检查 SCSS 变量与类名是否冲突
  - 确认组件容器高度与内边距设置
